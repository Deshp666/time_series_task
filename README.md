# Прогнозирование почасового спроса на велопрокат Capital Bikeshare

[Итоговый отчёт](artifacts/full/REPORT.md) · [Ноутбук для защиты](study_full.ipynb) · [Тестовая выборка](artifacts/full/test_data.csv) · [Таблица метрик](artifacts/full/summary.csv)

**Краткий итог.** На декабрьском тесте выбранные по осенней валидации NHITS и LSTM снизили среднюю абсолютную ошибку относительно недельного бейзлайна на 50,6% для суток и на 9,6% для недели. Theta показала наименьшую ошибку на обоих горизонтах в декабре. В ноутбуке сохранены таблицы и графики всех трёх моделей.

Проект сравнивает прогнозы числа аренд на 24 и 168 часов. Данные Capital Bikeshare за 2011–2012 годы содержат 17 379 наблюдаемых часов. После восстановления часовой сетки получено 17 544 часа. Для 165 часов сохранена отметка об отсутствии наблюдения. [Подготовленные данные](data/processed/hourly.csv) · [Метаданные источника и лицензии](data/raw/source.json)

## Эксперимент

Бейзлайн берёт число аренд в тот же час предыдущей недели. С ним сравниваются ARIMA, ETS, Theta, CES, MSTL, автоматические варианты ARIMA и ETS, три модели машинного обучения и три нейросети. Для каждой модели настройка выбирается по средней абсолютной ошибке на временной валидации. [Конфигурации и даты](configs/study.yaml)

| Этап | Даты выпуска прогнозов в 2012 году |
|---|---|
| Валидация и подбор настроек | 1 и 15 сентября, 1 и 15 октября |
| Калибровка прогнозных интервалов | 1, 8, 15 и 22 ноября |
| Тест | 1, 8, 15 и 22 декабря |

Модель обучается на наблюдениях до даты выпуска прогноза. Суточный тест покрывает четыре субботы. Недельный тест покрывает четыре последовательные недели.

## Воспроизведение

Использовались Python 3.11 и PyTorch 2.11 с CUDA 12.8. Для полного прогона нужна доступная видеокарта NVIDIA. Установите совместимую сборку PyTorch перед зависимостями проекта. [Инструкции PyTorch](https://pytorch.org/get-started/locally/) · [Версии пакетов эксперимента](requirements-target.txt)

```text
python -m pip install -e ".[dl,test]"
python -m bike_forecast doctor
python -m pytest -q
python -m bike_forecast run --profile full
```

Команда запуска использует сохранённую почасовую таблицу. При необходимости команда `python -m bike_forecast download` повторно загружает исходный архив и готовит данные. Ноутбук отображает сохранённые результаты.

## Итоговые результаты

Полный прогон завершил 488 заданий без ошибок. В таблице MAE — средний абсолютный промах в числе аренд за час. Для каждого горизонта сначала выбрана модель по осенней валидации, затем оценены её декабрьские прогнозы.

| Горизонт | Выбор по валидации | MAE модели в декабре | MAE недельного бейзлайна | Снижение MAE | Минимальный MAE в декабре |
|---|---|---:|---:|---:|---|
| 24 часа | NHITS | 38,99 | 78,92 | 50,6% | Theta, 22,70 |
| 168 часов | LSTM | 61,70 | 68,23 | 9,6% | Theta, 38,99 |

Для NHITS и LSTM выбрано входное окно в 336 часов. У Theta выбрана сезонность 168 часов. Theta сильнее всего отличается на окне с 22 декабря. На горизонте 24 часа её MAE на этом окне составил 11,08 против 77,05 у NHITS, на горизонте 168 часов — 36,69 против 135,79 у LSTM. Это декабрьский результат для дальнейшего исследования. Если выбирать модель по декабрьскому рейтингу, для проверки такого выбора потребуется новый период.

### Надёжность и стоимость прогноза

- **Сутки.** 95%-й интервал NHITS накрыл 96 из 96 наблюдений при средней ширине 325,50 аренды. Блочный bootstrap дал 95%-й интервал для разности MAE с бейзлайном от −76,08 до −3,77 аренды за час. В расчёте четыре суточных блока, все приходятся на субботы.
- **Неделя.** Покрытие 95%-го интервала LSTM в среднем по окнам составило 95,2%, средняя ширина — 395,98 аренды. Интервал разности ошибок с бейзлайном от −17,44 до +2,88 включает ноль. Средняя ошибка LSTM меньше, но данных недостаточно для уверенного вывода о её преимуществе.
- **Диагностика.** Тест Льюнга — Бокса выявил зависимость ошибок в двух из четырёх суточных окон NHITS и во всех четырёх недельных окнах LSTM при пороге 0,05. Это указывает на структуру в ошибках многокрокового прогноза. [Диагностика по окнам](artifacts/full/residual_diagnostics.csv)
- **Скорость.** На тестовых окнах обучение NHITS занимало в среднем 6,02 с, LSTM — 3,13 с, AutoARIMA — 236–238 с. AutoARIMA на обоих горизонтах дала более высокий MAE, чем выбранные нейросети. Время измерялось на одной машине, часть заданий запускалась параллельно. [Метрики и время](artifacts/full/summary.csv)

### Дополнительные проверки

На осенних сутках отключение календаря увеличило MAE NHITS с 44,20 до 52,53, а у случайного леса — с 51,13 до 56,58. При добавлении погоды с недельным лагом MAE вырос до 71,85 и 52,28 соответственно. Два дополнительных случайных зерна дали MAE NHITS от 43,15 до 46,47. Эти проверки описывают чувствительность моделей на осенних окнах.
